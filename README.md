# Space Miner

An idle game for Linux, written in Python with [pygame](https://www.pygame.org). Start on Earth, mine the asteroids orbiting it, and expand across the whole solar system - and beyond. Every planet has its own ore, its own fleet, its own colony and its own bonus.

![Early game on Earth](screenshots/01-earth-early.png)

- **No assets, no dependencies except pygame** - every planet, ship, asteroid and effect is drawn by code at start-up.
- **Idle-friendly** - your fleets keep mining while the game is closed (up to 8 hours), and it autosaves every 15 seconds.
- **A lot of content** - 12 planets, 8 ship types per planet, 58 upgrades per planet, 6 colony buildings per planet, 12 megaprojects, 30 techs, 22 Dark Matter perks, 9 kinds of random events, rotating quests, a **galaxy map with 15 enemy-held sectors**, **New Game+ with Stardust** and **165 achievements**. Sound effects are generated by code too, and there is a developer mode for testing.

## Download

Grab the latest build from the [Releases page](https://github.com/notyourbusinessss/PasstimeLinuxGame/releases/latest).

**Linux** (`space-miner-<version>-linux-x86_64.tar.gz`) - a single executable, no Python or pygame needed:

```sh
tar -xzf space-miner-*-linux-x86_64.tar.gz
cd space-miner-*-linux-x86_64
./space-miner                 # just run it, or...
./install.sh                  # ...add it to your applications menu (no root; ./install.sh --uninstall removes it)
```

The build needs a reasonably recent distro (glibc 2.35 or newer, e.g. Ubuntu 22.04+). On an older one, run it from source (below).

## Android

Space Miner also runs on Android phones and tablets (landscape).

![The phone layout: the canvas takes the shape of the screen](screenshots/53-android-planet.png)

**Install.** Download `space-miner-<version>-android.apk` from the [Releases page](https://github.com/notyourbusinessss/PasstimeLinuxGame/releases/latest), open it on the device and allow installing apps from this source when Android asks (the APK is debug-signed, so it is for sideloading, not the Play Store). Your save is private to the app.

**How it plays.** The whole game works with touch:

| Gesture | Action |
|---|---|
| Tap the planet view | Mine the nearest asteroid (tap anywhere; use several fingers at once) |
| Tap a button or a row | Press it (a tap that moves is a scroll, so you never buy by accident) |
| Drag a list up or down | Scroll it; let go while moving to fling it |
| Drag the galaxy map | Pan |
| Pinch the galaxy map | Zoom (two fingers also pan) |
| Double-tap a sector | Close look at its front |
| Back button | Leave the galaxy map (it never quits the game) |
| Home / switching apps | The game saves; when you come back it pays the progress you missed (up to 8 hours, like when the game is closed) |

![The galaxy map on a phone](screenshots/54-android-galaxy.png)

The canvas is made to match the shape of the screen (for example 1600x720 on a 20:9 phone), so it fills it without black bars; the buttons on the galaxy map are bigger and taps are forgiving. There is no Dev tab, and no Fullscreen or Size settings (the game always fills the screen). On a small phone the text is small - it is more comfortable on a tablet or a large phone.

**Build it yourself** (Linux, Java 17, about 10 GB of disk for the Android SDK and NDK; the first build takes a while):

```sh
pip install buildozer "cython==0.29.36"
buildozer android debug          # the APK ends up in bin/
```

`buildozer.spec` holds the settings and pins a python-for-android release that builds pygame 2.1.0 with Python 3.10; the release workflow builds the APK the same way for every `v*` tag. You can try the touch interface on a computer: `python3 space_miner.py --touch --resolution 1600x720` (the mouse acts as a finger).

> **Status:** the touch interface is tested with simulated gestures and a fuzz test, but the APK build itself has not been run yet. If the first run of the *Release* workflow fails on Android, the Linux release is still published and the build log is attached to the run.

## Quick start (from source)

```sh
git clone https://github.com/notyourbusinessss/PasstimeLinuxGame.git
cd PasstimeLinuxGame
./play.sh
```

`play.sh` installs pygame if it is missing and starts the game. You need Python 3.9+ and a desktop session.
Prefer to do it by hand?

```sh
pip install pygame
python3 space_miner.py
```

On distros where pip refuses to install into the system Python ("externally managed environment"), use a virtual environment:

```sh
python3 -m venv venv
./venv/bin/pip install pygame
./venv/bin/python space_miner.py
```

Missing Python or pip? Debian/Ubuntu: `sudo apt install python3 python3-pip python3-venv` - Fedora: `sudo dnf install python3 python3-pip` - Arch: `sudo pacman -S python python-pip`.

### Window, resolution and fullscreen

The window is resizable: drag its edges, maximise it with your window manager, or press **F11** (or start with `./play.sh --fullscreen`). The game scales smoothly to fit, with black bars if the shape of your screen is different.

The game can also be played at a **higher resolution**. A bigger canvas is not just a bigger picture - everything is laid out again, so you get more room: a taller and slightly wider side panel (more rows at once), a bigger and crisper galaxy map, and a larger field of asteroids around the planet.

| Size | Good for |
|---|---|
| 1280x720 | small screens and slower computers (the original layout) |
| 1600x900 | a window on a 1080p screen |
| 1920x1080 | fullscreen on a 1080p screen, or a window on 1440p / 4K |
| 2560x1440 | fullscreen on a 1440p screen, or a window on 4K |

**Auto** (the default) picks the biggest size that fits your screen - what fits in a window, or the whole desktop's resolution when you go fullscreen, so F11 on a 1080p monitor gives you a native 1920x1080 picture. Choose a fixed size with the **Size** button in *Awards -> Stats -> Settings* (it is remembered) or for one run with `--resolution 1920x1080`. Bigger sizes need a faster computer: on the test machine a frame takes about 6 ms at 1280x720, 10 ms at 1920x1080 and 18 ms at 2560x1440.

![1920x1080: a taller panel, more asteroids around the planet](screenshots/49-hires-planet.png)

![The galaxy map at 1920x1080](screenshots/50-hires-galaxy.png)

Command-line options: `--fullscreen`, `--resolution WxH`, `--touch`, `--debug` (verbose log, also printed in the terminal), `--dev` ([developer mode](#developer-mode)), `--version`, `--help`.

Your save lives in `~/.space_miner_save.json`. Delete it (or use *Awards -> Stats -> Hard reset*) to start over.

## How the game works

### 1. Mine the asteroids

The planet you are visiting sits in the middle of the screen with asteroids orbiting it. Each click mines ore, shown in that planet's own ore type. Buy **ships** and they circle the planet, laser the asteroids and mine for you. Ships cost the same ore they mine, and each one gets pricier (+15%) than the last.

![A developed fleet on Mars](screenshots/03-mars-fleet.png)

There are 8 ship **classes**, from the humble Drone to the Black Hole Engine, and **every planet has its own fleet of them**: a Dune Rover on Mars and a Ring Skipper on Saturn are both Drones (same price and output), but they have their own names, descriptions, **hulls, colours, flight paths and lasers**, so you can tell where you are by the fleet alone. A new ship type shows up as `???` once you own the one before it.

| Moon | Silver landers on spindly legs | Hop in the low gravity | A stream of shots |

### 2. Upgrades

The **Upgrades** tab lists what you can buy on the current planet with its ore: ship multipliers that unlock as you own more of a ship (x2, x2, x3, x3, x5), stronger clicks, drills that make each click also mine a share of your ore/sec, and *Star Charts* that boost the whole planet. **Buy everything affordable** is one click.

![Upgrades](screenshots/05-upgrades.png)

### 3. Unlock and travel to new planets

Open the **Planets** tab. The next planet is unlocked by paying ore from the worlds *behind* it - usually the previous planet's ore, plus a little of the one before that, plus credits later on. Unlocking gives you:

1. a **new ore** to mine on its own asteroids,
2. an empty **fleet, upgrade shop and colony** to build,
3. a permanent **planet bonus** that helps everywhere (clicks, cheaper ships, production multipliers, offline progress...).

Once a planet is unlocked, click it in the bottom strip (or the Planets tab) to fly there. A short hyperspace jump later you are mining a new ore. **Every unlocked planet keeps producing while you are somewhere else.**

### 4. Colonies and megaprojects

| Fusion Reactor | credits | +2.5% ALL production / level |

### 5. Tech tree

Science buys the **Tech** tree: 30 techs with prerequisites. They include automatic ship buying and upgrade buying (they only ever spend up to 25% of a stockpile so you can still save for planets), automatic crate collection, big production multipliers, cheaper ships, head-start ore after a Warp and more. Techs stay forever.

![Tech tree](screenshots/06-tech-tree.png)

### 6. Quests, crates and random events

- **Quests** - three rotating goals (click asteroids, buy ships, mine ore, grab crates, upgrade colonies, resolve events...). Fill the bar and claim ore, credits, science or a Mining Frenzy.
- **Supply crates** - a golden crate drifts across the screen every minute or so. Grab it for ore, credits or a x7 *Mining Frenzy*.
- **Random events** - every few minutes something happens at the planet you are on: meteor showers, pirate raids, solar flares, a cosmic lottery, derelict ships, alien traders, research grants, distress signals and, very rarely, a whisper from the void. Most give you a risky option and a safe one.

![A random event](screenshots/08-random-event.png)

### 7. The galaxy: enemies, campaigns and raids

Once you unlock **Mars** the **galaxy map** opens (the spiral button at the far left of the planet strip, or press **G**). Beyond the solar system lie **15 sectors** held by hostile factions - Pirate Syndicate, Zorgon Hive, Crystalline Collective, Ironclad Dominion, Void Cult and, waiting on the far edge, the final boss **The Devourer**. Sectors you have not scouted yet stay hidden in the fog; you can only attack sectors that border territory you already hold.

![The galaxy map](screenshots/18-galaxy-map.png)

**Fleet power.** Your fleet's strength comes from the ships you own on all your planets (bigger ships count for far more), boosted by your Weapons upgrades, your Defense Grids, your overall production bonus and the sectors you have liberated. It is shown on the Galaxy tab.

**Campaigns.** Pick a frontier sector on the map or in the *Galaxy* tab and press **ATTACK** (or **DECLARE WAR**, if you are at peace with that faction - see [War and peace](#war-and-peace)). Your fleet's power is committed and a campaign timer runs while you keep playing (or while the game is closed). When it ends the game rolls the dice using the win chance shown beforehand (it depends on your fleet power compared with the enemy's):

- **Victory** - the sector is liberated and its **permanent bonus** is yours (they survive Warps), and you lose about 1% of your ships.
- **Defeat** - you lose about 8% of your ships and can try again once you are stronger.

![The Galaxy tab](screenshots/19-galaxy-tab.png)

![A sector liberated](screenshots/22-sector-liberated.png)

#### Close look: the frontlines

The galaxy map is a zoomable tactical view. Scroll the **mouse wheel** to zoom towards the cursor, **drag** to pan (or use **+** / **-** and the arrow keys), and use the buttons in the corner: **+**, **-**, **FIT** (the whole galaxy) and **FRONT** (zoom in on the front of the selected sector - **Z** and a double-click on a sector do the same). A mini-map shows where you are once you zoom in, and you can click it to jump somewhere else.

![The galaxy map with its frontlines](screenshots/34-galaxy-frontlines.png)

Every lane between a sector of yours and an enemy sector is a **front**. The battle line sits where the two forces balance: the stronger your fleet is compared with that sector's defenders, the closer to the enemy the line is pushed, and a running campaign pushes it further. Zoomed out you see a clash marker on each front; zoom in and the front turns into a battle:

![Close look at a front](screenshots/35-frontline-closeup.png)

- **Both fleets** are drawn as swarms facing each other across the battle line. The more power, the bigger the swarm; your ships are the types you actually own, the enemy's are its faction's ships. Lasers and explosions fly while the fight goes on.
- **Power split.** A small bar at each front shows your share of the combined strength and your win chance.
- **Labels** fill in as you zoom: the enemy sector's faction, power and a status (*Dominating*, *Advantage*, *Stalemate*, *Under pressure* or *Outgunned*), and for your own sectors their reward.
- **Garrison shields.** Every sector of yours that borders the enemy wears shield arcs, coloured by how likely it is to hold against a counter-offensive: green *Secure* (80% or more), yellow *Holding* (50% or more), red *Vulnerable*. Fortifying a sector against an incoming attack gives it a gold ring.
- **Incoming attacks** (with the Intel upgrade) appear as an enemy fleet sailing down the lane with a countdown, so you can watch a counter-offensive arrive and see exactly which sector it is aimed at.

![A counter-offensive on its way](screenshots/37-incoming-closeup.png)

The **Galaxy tab** has **Close look at the front** and **Zoom out** buttons and a **Front report** card for the selected sector: the status of the fighting, the power split, where an attack would launch from and which sectors border it - or, for a sector you hold, its garrison, which enemies can reach it and its chance to hold. Clicking the card (or a sector in the list) takes the map there.

![The front report](screenshots/36-front-report.png)

**Armory.** Credits and Science buy permanent military upgrades:

| Upgrade | Max level | Effect |
|---|---|---|
| Weapons | 20 | Fleet power x1.2 per level |
| Armor | 12 | Fleet losses -6% per level |
| Engines | 15 | Campaigns 8% faster per level |
| Shields | 10 | Raid losses -8% per level |
| Intel | 8 | Enemy attacks are announced earlier and in more detail (see *The Threat Director* below) |

**Raids.** While you are at war with a faction whose sectors border your territory, it **raids your planets**. Your ships and **Defense Grid** buildings (+10% defense per level) fight them off: you get credits for repelling a raid, or lose some of that planet's ore if the defence fails. If you are on the raided planet you watch it happen:

#### War and peace

The galaxy starts at peace, and **nobody attacks you until a war starts**. A war starts in exactly one of two ways: you decide to invade, or you are invaded.

![The Factions card: peace, tension and the sector card](screenshots/39-peace-factions.png)

- **You invade.** Press **DECLARE WAR** on a sector of a faction at peace (the button asks you to click twice). The campaign starts, and from then on that faction's fleets raid your planets and counter-attack your border sectors.

  ![Invading means war](screenshots/40-declare-war.png)

- **You are invaded.** Every faction that borders your territory builds **tension** towards you, shown on the *Factions* card in the Galaxy tab. About 90 minutes of border contact fills it (the Pirate Syndicate lose patience first, the Crystalline Collective last, and the more sectors you hold the faster it goes). At 80% you get a warning; at 100% the faction **declares war** and opens with a counter-offensive on your weakest border sector, or a raid.

  ![A faction invades you](screenshots/43-invasion.png)

Only factions at war with you attack, and only from the sectors that border you - the rest of the galaxy stays quiet. Everything described below under *Raids* and *The Threat Director* happens during a war.

**Ending a war.** After 10 minutes of war you can **sue for peace** (it costs about ten minutes of your credit income, and you cannot do it while your fleet is attacking that faction). Their fleets turn back and a **truce** holds for 45 minutes: no tension, no attacks. Attack them during the truce and it is broken (they get angrier); once it runs out the tension starts building again. A faction with nothing left on the map has nothing to fight with, so that war ends by itself.

On the map the fronts show it: at peace the two fleets just face each other across a calm ring that fills up with tension; at war the front is a battlefield with lasers and explosions.

![A front at peace](screenshots/41-front-at-peace.png)

![War declared](screenshots/42-war-declared.png)

#### The Threat Director

The enemy is not random: while you are at war, a **Threat Director** watches how strong you are compared with the enemy sectors that border you and decides when to strike. The Galaxy tab shows its **Threat level** card:

![The Threat level card, incoming attacks and faction hostility](screenshots/28-threat-director.png)

- **Aggression** (Quiet, Watchful, Hostile, Aggressive, Warlike) rises when your fleet is weak next to the nearest enemy, when some of your planets are poorly defended and when you have been attacking a faction recently. The more aggressive the enemy, the more often it attacks.
- **Raids** hit your planets, and the enemy prefers the weakly defended ones. They come in three sizes:

| Raid | Appears once you hold | Power | Planets hit | If you hold | If you lose |
|---|---|---|---|---|---|
| Small raid | - | x1 | 1 | credits | 4% of that planet's ore |
| Regional assault | 3 sectors | x3 | 1 | 4x the credits | 10% of that planet's ore |
| System invasion | 8 sectors | x6 | 3 at once | 10x the credits | 14% of each planet's ore |

  Your Shields upgrade reduces what a lost raid costs.
- **Counter-offensives** try to **retake a sector you liberated** that borders enemy territory. Each sector is defended by its **garrison** (your fleet power when you took it, never less than half your current fleet). If it falls you lose that sector's permanent bonus until you liberate it again (which earns the *Comeback* achievement).
- **Hostility.** Every campaign you start angers the faction you attack: its raids and offensives hit up to 2x harder, and the anger fades over a couple of hours.
- **Grace periods.** The enemy never attacks while the game is closed, and stays quiet for 10 minutes after you load a save, 15 after a Warp and 20 after an Ascension.

**Intel** decides how much you know in advance. Each level adds warning time (raids: 15 s + 45 s per level, counter-offensives: 60 s + 100 s per level), and higher levels reveal more:

| Intel level | You are told |
|---|---|
| 0 | Nothing: the raiders just arrive |
| 1 - 2 | "Unknown ships detected" |
| 3 - 4 | Who is coming and which planet or sector is the target, and you can Fortify it |
| 5 - 6 | ...plus the attack's power |
| 7 - 8 | ...plus your exact chance to hold |

Incoming attacks show up on the HUD and as a dashed red lane on the galaxy map, each with a countdown:

### 8. Warp (prestige)

When progress slows down, open the **Warp** tab. Warping resets the ore, ships and upgrades on every planet, but you keep your unlocked planets, colonies, megaprojects, techs, credits, science and **Dark Matter**.

- Dark Matter total = (ore mined this cycle / 1 billion) ^ 0.25, so you earn it from everything you mine, not just the last run.
- Your Dark Matter gives a permanent production bonus of `1 + 0.4 x sqrt(Dark Matter)`.
- You can also *spend* Dark Matter on 22 perks (all production x2, x3 or more, offline progress at 100%, faster travel, bigger starting supplies...).

![Warp drive and Dark Matter perks](screenshots/09-warp.png)

A good rule of thumb: warp when the "Warp now for" number is at least as big as the Dark Matter you already own.

### 9. Ascension (New Game+)

Once you have defeated **The Devourer** on the Void Throne the *Ascension* section of the **Warp** tab unlocks. **Ascending** starts a brand-new **cycle** (New Game+): the whole universe resets - your planets, ships, colonies, tech, credits, science, Dark Matter, armory, liberated sectors and megaprojects are gone - but you keep:

- all your **achievements** (and their production bonus) and statistics, and
- **Stardust**, a new permanent currency you earn every time you Ascend.

![The Ascension screen](screenshots/24-ascension.png)

Stardust does two things:

1. Your total Stardust gives a permanent **production bonus** (`1 + 0.4 x sqrt(Stardust earned)`).
2. You can spend it on **Stardust perks**: start every cycle with extra planets already unlocked, cheaper tech, big production and fleet-power multipliers, and - most importantly - perks that let you **keep** megaprojects, armory levels and liberated sectors when you Ascend. Each Ascension also earns about 10% more Stardust than the last.

![Stardust perks](screenshots/25-stardust-perks.png)

The price of going again: in cycle *n* planets and megaprojects cost more (`1 + 10 x (n - 1)` times the original price) and enemy fleets are 1.25x stronger per cycle. Even so, the first New Game+ cycle takes roughly half as long as the first run, and later cycles settle at about 55 - 65 hours each in the balancing bot's runs. The current cycle is shown in the top-left corner and on the Stats page.

### Pacing

The pacing (planets, megaprojects and sector liberations) was tuned with a bot that plays the game headless (see below). A player who checks in every few minutes should reach roughly:

| Milestone | Roughly after |
|---|---|
| Moon | 12 minutes |
| Mars | 45 minutes |
| Venus | 1.5 - 3 hours |
| Mercury | 3 - 8 hours |
| Ceres / Jupiter | 5 - 17 hours |
| Saturn / Uranus | 15 - 33 hours |
| Neptune / Pluto | 25 - 55 hours |
| Proxima b | 45 - 70 hours |
| Every megaproject built | 50 - 100 hours |
| The final boss (Void Throne) | 65 - 90 hours |
| First Ascension, then every later cycle | after the boss; cycles of ~40 - 65 hours |

Enemy raids and counter-offensives are included in these numbers (the bot defends itself with Intel and Fortify); small raids that get through only cost a little ore. Warping a few times along the way speeds this up a lot. Playing less often just means the numbers go up while you are away.

## Tips

- Early on, click a lot - clicks are strong until your first few ships. Buy a Habitat Dome and a Research Lab on Earth as soon as you can afford them: Credits and Science unlock the tech tree.
- Don't spend everything. Unlocking the next planet needs a big stockpile of the previous planet's ore, so stop buying ships on it once the progress bar is close.
- Visit new planets right after unlocking them: clicking there bootstraps a fleet quickly, and each planet bonus helps every other planet.
- Research *Auto-Drones* and *Auto-Engineers* early and the game mostly plays itself while you travel.
- Zoom into your fronts (**Z**): sectors with red *Vulnerable* shields are the ones the enemy will take back, so Fortify them when an attack is announced - or just send the fleet out and win the fight first.
- Check the Galaxy tab every so often: a glowing dot appears on it when a campaign has a good win chance. Liberating sectors is one of the biggest production boosts in the game.
- After the boss, Ascend: spend the Stardust on the planet-starting perks and the "keep" perks first - they make every later cycle much faster.
- Put credits and science into the Armory (Weapons first) - your win chances jump quickly, and Armor makes failed campaigns cheaper.
- Peace is yours to break: stay at peace while you build up and invade when you are ready - but the factions on your border will not wait for ever, so keep an eye on their tension bars. A ceasefire is cheap once a war has dragged on.
- Build Defense Grids on planets that keep getting raided, and buy a few levels of Intel: with the target named you can Fortify it and turn a lost raid into a won one.
- Don't let your fleet fall far behind the enemy next to you: that is what makes the Threat Director aggressive. Attacking one faction over and over also makes it hit back harder.
- Open the Awards tab now and then: the nearest-to-done achievements sit at the top and every one is a permanent production bonus.
- If a dot is glowing on a tab, there is something affordable in it.

### Balancing tools

```sh
python3 sim.py hours=100 interval=120        # bot checks in every 2 minutes for 100 simulated hours
python3 sim.py hours=100 interval=900 quiet=1 # only print unlocks and megaprojects
python3 sim.py hours=400 interval=120 quiet=1   # also ascends and spends Stardust: look for the ASCEND lines
python3 calibrate.py interval=120             # re-derive unlock/project/sector values (takes an hour or so)
python3 tools/fuzz.py frames=5000 seed=7      # random clicks, drags, scrolls and keys in several game states; lists any crash
```

The knobs live in `core.py` (`UNLOCK_LOG`, `PROJECT_LOG`, `SECTOR_LOG`, `TUNE` - including `cdiff`, `cpow` and `sdcoef` for New Game+).

### Making a release

1. Bump `__version__` in `version.py` and add a section for it to `CHANGELOG.md`.
2. `./packaging/build_linux.sh` builds `dist/space-miner-<version>-linux-<arch>.tar.gz` (with a `.sha256`) on your machine: a one-file executable made with PyInstaller, the installer, the icon and the docs.
3. For a published release, push a tag: `git tag v1.0.1 && git push origin v1.0.1`. The *Release* workflow runs the self-test, builds the files and creates the release on the Releases page, using the changelog section as the notes. The *CI* workflow runs the self-test on every push and pull request.

### Self-test

`python3 space_miner.py --selftest` runs the game headless for a few seconds and exercises buying, unlocking, travelling, events, quests, warping and saving. It writes a few `shot_*.png` images next to the script and uses a temporary save, so it never touches your real one. Add `--dev` to also fire every developer cheat once.

## Troubleshooting

- **Something went wrong or the game crashed** - the game writes a log, so there is always a record of why. Look in `~/.local/state/space-miner/` (the Stats page has an **Open log folder** button):
  - `space-miner.log` - start-up details (version, system, graphics driver), saves and loads, warps, setting changes and every error with its full traceback and the state of the game at that moment. It keeps the last few megabytes.
  - `crash-<date>.txt` - written when the game has to stop; it has the error, the system details and the end of the log.
  - `faulthandler.log` - a stack dump if the program dies for a reason Python cannot catch (a crash inside the graphics library, for example).

  An error in one frame is logged and the game carries on, and the Stats page shows how many errors were logged this session. If you report a bug, please attach `space-miner.log` and any `crash-*.txt`. Run with `--debug` for more detail.
- **My save is gone or broken** - a backup (`~/.space_miner_save.json.bak`, refreshed every 10 minutes) is used automatically if the save is damaged, and a save that cannot be read is never overwritten silently: a copy named `.unreadable-<date>` or `.broken-<date>` is kept next to it.

- **`ModuleNotFoundError: No module named 'pygame'`** - run `pip install pygame` (or use `./play.sh`).
- **No window appears over SSH / in a container** - the game needs a display. Run it from a desktop session.
- **The window is bigger than my screen / everything is tiny or huge** - choose another size with the **Size** button in the Stats page, or start with `--resolution 1280x720`. *Auto* normally picks a size that fits.
- **The window is small / fullscreen does not work** - the game needs a desktop session with a graphics renderer for the resizable, scaled window; otherwise it falls back to a fixed 1280x720 window and the Fullscreen button is greyed out. Try running it under X11 or Wayland (not over a plain SSH session), and make sure your graphics drivers are installed.
- **Text looks off** - the game asks for DejaVu Sans, Liberation Sans or Arial and falls back to pygame's default font.
- **Reset everything** - delete `~/.space_miner_save.json` (and `~/.space_miner_save.json.bak`), or use *Awards -> Stats -> Hard reset*.
